# Lego

Этот репозиторий — пользовательский форк [go-acme/lego](https://github.com/go-acme/lego), ACME-клиента и библиотеки на Go для получения и обновления TLS-сертификатов.

Основа: **Lego v4.35.2** (исходный коммит `537f2ed`). Форк содержит локальную доработку проверки ACME challenge для случая, когда сервер не возвращает URL авторизации.

## Изменения относительно v4.35.2

В [`challenge/resolver/solver_manager.go`](challenge/resolver/solver_manager.go) добавлена обработка пустого `AuthorizationURL`:

- Если URL авторизации отсутствует, статус запрашивается напрямую по URL challenge через `core.Challenges.Get(chlg.URL)`.
- Полученный статус проверяется через `checkChallengeStatus`: успешная проверка завершает ожидание, незавершённая приводит к повторному запросу, ошибка останавливает проверку.
- Если `AuthorizationURL` указан, используется исходная логика опроса авторизации.

Правка добавлена коммитом `5ed0033`. Исходный код основан на v4.35.2; последующие версии оригинального проекта в эту основу не включены.

## Использование

Для использования этой доработки собирайте приложение из исходников данного форка. Готовые сборки оригинального проекта не содержат эту правку.

Описание CLI, библиотеки и DNS-провайдеров доступно в [документации Lego](https://go-acme.github.io/lego/). Онлайн-документация может описывать более новую версию; документация из исходной версии находится в каталоге [`docs`](docs).
